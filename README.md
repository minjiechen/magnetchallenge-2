## Project Overview

This project is a challenge platform that enables users to participate in various coding challenges, track their progress, and improve their skills. The aim is to provide an engaging environment for developers and aspiring coders.

## Installation Instructions

To install the application, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/minjiechen/magnetchallenge-2.git
   ```

2. Navigate into the project directory:
   ```bash
   cd magnetchallenge-2
   ```

3. Install the required dependencies:
   ```bash
   npm install
   ```

## Usage

To start the application, use the following command:
```bash
npm start
```

Visit `http://localhost:3000` in your web browser to see the application in action.
